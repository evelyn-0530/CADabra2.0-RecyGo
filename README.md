# CADabra2.0-RecyGo
Source code for RecyGo, an AI smart recycling and rewards platform developed for SEA 2026.

Team: CADabra 2.0  
Competition: Southeast Asia Engineering Design Competition 2026  
Domain: Urban Waste & Recycling Management

## Project Overview

RecyGo is an AI-powered smart recycling system that classifies waste, sorts it automatically, monitors bin fill level, and rewards users through an app.

The system includes:
- AI waste classification using YOLO
- Arduino-based sorting control
- Smart bin monitoring using ultrasonic sensor
- Flutter app for rewards, missions, and bin connection
- Python digital simulation for urban-scale impact analysis
